# Чек-лист будущих доработок

Внутренний файл проекта. На сайте не отображается. Нужен только для фиксации идей, которые решено сделать позже.

## В планах

- [ ] Личный кабинет клиента.
  - У каждого клиента свой приватный кабинет.
  - Клиент самостоятельно заполняет запрошенную информацию и анкеты.
  - Клиент может отправлять обновления между сессиями.
  - Новые данные попадают в общую историю клиента и учитываются ИИ-помощником по клиенту.
  - До реализации отдельно спроектировать доступ, права, приватность и разделение данных клиентов.

- [ ] Голосовой ввод в заметках.
  - Добавить запись голосового сообщения прямо в общие заметки и заметки клиента.
  - Использовать высокоточную транскрибацию речи, а не браузерную приблизительную диктовку.
  - После расшифровки предлагать два режима AI-редактирования: «Коротко» и «Раскрыть мысль полностью».
  - По возможности хранить исходную расшифровку отдельно от отредактированной версии, чтобы смысл не терялся.
  - Добавить удобный сценарий для фиксации мыслей о будущих функциях голосом.

- [ ] Связать общие заметки с чек-листом будущих доработок.
  - В заметке можно будет пометить мысль как «Идея / На будущее».
  - Такие идеи должны попадать в отдельный список будущих доработок, не смешиваясь с обычными рабочими заметками.
  - Пока этот интерфейс не сделан, внутренний файл `internal/FUTURE_CHECKLIST.md` остаётся основным чек-листом проекта.

## Правило ведения

Если во время разработки явно звучит «потом», «в будущем», «позже сделаем», «надо будет добавить» и аналогичная формулировка про будущую функцию — добавлять её сюда, а не оставлять только в истории чата.
