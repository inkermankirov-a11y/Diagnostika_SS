# Чек-лист будущих доработок

Внутренний файл проекта. На сайте не отображается. Нужен только для фиксации идей, которые решено сделать позже.

## В планах

- [ ] Голосовой ввод заметок.
  - В «Общих заметках» и заметках клиента можно записать голосовое сообщение.
  - После записи аудио автоматически транскрибируется в текст с максимально точной расшифровкой.
  - Перед сохранением можно выбрать обработку ИИ: «Коротко» — сжать мысль без потери смысла; «Подробно» — привести речь в ясный, связный текст и полностью раскрыть мысль.
  - Отдельно решить, нужно ли хранить исходное аудио, исходную расшифровку и отредактированную версию текста.

- [ ] Раздел «Планы / На будущее» внутри общих заметок.
  - Использовать как доступный из интерфейса список будущих идей и доработок.
  - Идеи, которые Женя диктует или пишет как «потом», «в будущем», «надо будет сделать», можно переносить туда автоматически или по команде.
  - Внутренний файл `internal/FUTURE_CHECKLIST.md` остаётся технической резервной копией плана и не отображается на сайте.

- [ ] Личный кабинет клиента.
  - У каждого клиента свой приватный кабинет.
  - Клиент самостоятельно заполняет запрошенную информацию и анкеты.
  - Клиент может отправлять обновления между сессиями.
  - Новые данные попадают в общую историю клиента и учитываются ИИ-помощником по клиенту.
  - До реализации отдельно спроектировать доступ, права, приватность и разделение данных клиентов.

## Правило ведения

Если во время разработки явно звучит «потом», «в будущем», «позже сделаем», «надо будет добавить» и аналогичная формулировка про будущую функцию — добавлять её сюда, а не оставлять только в истории чата.
