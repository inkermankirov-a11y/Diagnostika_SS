# DiagnostikaSS — два независимых сайта

В репозитории находятся две полные, отдельно редактируемые копии веб-приложения «Психологическая диагностика»:

- **[DiagnostikaSS.com/](DiagnostikaSS.com/)** — основной сайт (прежняя версия Diagnostika SS).
- **[DiagnostikaSS.ru/](DiagnostikaSS.ru/)** — второй самостоятельный экземпляр.

Обе папки содержат **свои полные** HTML, CSS, JS, вложенные модули, настройки и ресурсы. Изменения в одной папке **не** изменяют автоматически другую.

## Открыть через GitHub Pages

При публикации ветки `main` из корня репозитория:

- `https://inkermankirov-a11y.github.io/Diagnostika_SS/DiagnostikaSS.com/`
- `https://inkermankirov-a11y.github.io/Diagnostika_SS/DiagnostikaSS.ru/`

Корневой `index.html` перенаправляет посетителей на `DiagnostikaSS.com/`, сохраняя старую точку входа.

**Внимание:** имена папок — ещё не купленные и не подключённые домены `diagnostikass.com` и `diagnostikass.ru`. Доменную регистрацию, DNS, HTTPS и настройку хостинга нужно выполнять отдельно.

## Данные и внешние интеграции

- Копирование программного кода **не** копирует персональные данные клиентов.
- Основной сайт сохраняет прежние ключи `localStorage` (чтобы не потерять данные на исходном GitHub Pages origin).
- На втором сайте `DiagnostikaSS.ru` браузерные ключи `localStorage` изолированы префиксом, даже пока оба сайта доступны на одном `github.io` origin.
- Если используется Google Drive, n8n, формы или внешняя база, для **полной изоляции** потребуются отдельные настройки этих сервисов.
- Обновление погоды через GitHub Actions распространяет `weather-data.json` на обе копии, не синхронизируя их код.

## Разработка

Корневые исходные файлы оставлены в репозитории для совместимости с существующими проверками GitHub Actions. **Публичный сайт в корне больше не запускается**, а перенаправляет на `DiagnostikaSS.com/`. Новые изменения вносите непосредственно в нужную папку — `DiagnostikaSS.com/` или `DiagnostikaSS.ru/`.

Персональные клиентские данные не следует загружать в публичный репозиторий.
