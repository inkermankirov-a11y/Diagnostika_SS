# Diagnostika-Web

Статическая веб-версия программы «Психологическая диагностика».

## Что работает

- карточки клиентов;
- поиск клиентов;
- общий запрос;
- ситуации и уровень 1–10;
- убеждения;
- вторичные чувства;
- глубинные убеждения;
- один или несколько инстинктов;
- желаемый результат;
- автосохранение в браузере;
- экспорт/импорт всей локальной базы JSON;
- экспорт диагностики клиента в TXT.

## Хранение данных

Данные сохраняются в `localStorage` браузера на конкретном устройстве. Они **не отправляются в GitHub**.

Не загружайте в публичный репозиторий исходную папку `DATABASE` из настольной версии: в ней содержатся персональные данные клиентов.

## Публикация через GitHub Pages

1. В корне репозитория должны находиться `index.html`, `styles.css`, `app.js`, `.nojekyll` и `README.md`.
2. GitHub → Settings → Pages.
3. Source: `Deploy from a branch`.
4. Branch: `main`, folder: `/ (root)`.
5. Save.

Главный файл — `index.html`.
